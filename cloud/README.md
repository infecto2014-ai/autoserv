# TOP-СЕРВИС · Cloud CRM

Закрытая CRM автосервиса для Sites и Cloudflare Workers. Данные хранятся в D1. Локальный вариант Next.js/PostgreSQL и Windows-запуск описаны в корне репозитория.

## Рабочий сценарий

В «Заказах» приёмщик оформляет визит по марке, телефону и жалобе. CRM сохраняет клиента и автомобиль либо использует явно выбранные записи. После приёмки открывается карточка заказа с осмотром. Отметьте нужные пункты, сохраните осмотр и перенесите позиции в заказ.

В разделе «Работы и запчасти» у каждой позиции есть решение клиента и отметка выполнения. Детали клиента и отложенные позиции исключаются из оплаты. Скидка применяется только к работам. Оплата и возвраты проводятся через журнал платежей. Сверка прежнего расчёта сохраняет отдельный исходный снимок, до сверки можно принимать оплату и открывать прежние документы.

Группа «Готов к выдаче» открывает выдачу с сохранением акта выполненных работ в PDF. В акт можно включить рекомендации. Выдача доступна с долгом. После выдачи можно внести доплату, исправить заказ и сформировать новую версию акта. Предыдущие версии остаются в «Документах».

На «Обзоре» видны текущие группы заказов, завершённые за период, поступления и текущий долг. Границы периода — календарные дни в Europe/Kaliningrad. Из суммы долга можно открыть список должников. В «Клиенты и авто» общие поиск и фильтр дат открывают историю обращений. «Сотрудники» — справочник мастеров для назначения.

## Доступ

Вход и выход обслуживает Sites через ChatGPT. Первый допущенный владелец получает ADMIN. Доступ приёмщика требует допуска к Site и профиля CRM с разрешённым email. Добавление записи мастера в справочник не создаёт учётную запись для входа.

## Разработка и проверка

Нужны Node.js 24 и Poppler с командами `pdfinfo`, `pdftotext`, `pdffonts` и `pdftoppm`. Все команды выполняются из `cloud/`.

```sh
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser
```

Для уже установленного Chromium можно использовать `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`. Playwright запускает и останавливает временный сервер с SQLite в памяти. Сценарий проходит реальный Worker и сохраняет скриншоты и PDF в `cloud/test-results/`. В GitHub Actions результаты прикладываются к запуску как артефакт `cloud-reception-workflow`.

Для управляемого предпросмотра из настроенной среды вызовите `sites-preview start /путь/к/репозиторию/cloud` и откройте URL, возвращённый командой. Скрипт проекта `npm run dev` собирает приложение, использует `PORT` среды (по умолчанию 4173) и работает с тестовым приёмщиком и пустой SQLite в памяти. Его данные сбрасываются при остановке. Тестовый сервер предназначен для локальной разработки и браузерного прогона.

## Сборка и данные

`npm run build` создаёт Worker ES module `dist/server/index.js` со встроенными UI и шрифтами. Диспетчер Sites передаёт идентификацию пользователя production Worker. Dev-сервер и его тестовые заголовки находятся в `tests/dev-server.ts` и не входят в сборку и публикацию.

Схема принадлежит миграциям в `drizzle/`. Платформа применяет их при публикации. `.openai/hosting.json` содержит Site ID и логический D1 binding `DB`. Перед изменением рабочей базы сохраняется её резервная копия.
