# План реализации

Коммиты и push запрещены без разрешения пользователя. Уровни S/M/L описывают сложность; основной исполнитель не имитирует переключение режима текущей сессии. Независимые задания передаются агентам доступными средствами.

1. **M/S — инструменты:** project-local Superpowers и UI UX Pro Max, версии, лицензии, проверка UX поиска. Файлы .agents/skills и docs/TOOLS.md.
2. **L — данные и каркас:** Prisma schema + SQL migration, Compose, env, seed, серверная валидация; проверить миграцию на PostgreSQL, Prisma validate, typecheck.
3. **L/M — доступ и CRUD:** защищённый вход, роли, клиенты/автомобили/сотрудники/каталог. Реальные операции БД; проверка авторизации и истории.
4. **L — заказ и осмотр:** версии, статусы, строки, альтернативные запчасти, расчёты/оплаты/аудит. Unit тесты денег/статусов и интеграционные тесты сценария.
5. **L — документы:** снимок + сохранённый PDF акта/заказа, A4/кириллица/переносы/табличная шапка; тесты PDF и извлечение текста.
6. **M/S — интерфейс:** адаптивная русская CRM, формы с ошибками, реальный поиск, осмотр и PDF. E2E через браузер.
7. **L/M — проверка и передача:** lint/typecheck/unit/integration/e2e/build; backup/restore; README, CI, архив проекта без env/node_modules/БД. Итоги и ограничения в docs/PROGRESS.md.

После каждого контрольного этапа обновлять docs/PROGRESS.md только по фактическим результатам.
